01ABOUT THIS LIBRARY

Research that
moves us forward.

This library brings TERI reports together in one searchable place. Each document stays intact, with its own report page, metadata and original file link.

The question assistant uses local text extraction and keyword retrieval. It shows report passages with page citations instead of generating claims from general model knowledge. Scanned pages, charts and complex tables may not be fully searchable.
